# 🌙 Luneya

> Less noise. More meaning.

Luneya is a calm, text-first social platform designed for teenagers aged 13–17.

This website serves as the public introduction to the project, explaining the platform's vision, safety-first approach, core features, and guiding principles.

Unlike traditional social media platforms that focus on endless scrolling, engagement metrics, and public profiles, Luneya is built around meaningful conversations, shared interests, privacy, and intentional connection.

## What's Included

* Modern responsive landing page
* Light and dark theme support
* Safety Guide
* Community Rules
* Report Abuse page
* Trust & Safety information
* Age Requirements policy
* Privacy Policy
* Terms of Service
* Cookie Policy

## Design Philosophy

The website follows a calm and minimal design language inspired by thoughtful reading experiences rather than attention-driven social platforms.

Key principles include:

* Simplicity over complexity
* Privacy by default
* Clear communication
* Accessibility
* Safety-first design

## Technology

Built using:

* HTML
* CSS
* Vanilla JavaScript

No frameworks. No unnecessary dependencies.

The website is currently complete and serves as the foundation for the Luneya project.
